# Rumor: Japanese photon device erases human memories

Logged 2026-10-03. Source tweet: https://x.com/NightSkyToday/status/2106229000653668474

## Verdict

False as written. There is no Japanese photon device that erases memories from a human brain. The attached images are a Men in Black still and a stock brain illustration.

## The real seed

Kyoto / Osaka work by Akihiro Goto, Yasunori Hayashi, and colleagues. Optogenetic probe (SuperNova fused to cofilin) in mice. Light inactivates cofilin at synapses, erases long-term potentiation in a chosen window, and can wipe a just-formed fear memory in the hippocampus or amygdala. Published around 2021 (Science). A later Kyoto grant (KAKENHI-PROJECT-24K22001) is trying to push the same idea toward a less invasive PTSD method. Still animals.

Related, not the same: Tohoku astrocyte optogenetics can bias whether a fear memory sticks. Tonegawa-line engram work can silence or reactivate mouse memories with light. None of this is a handheld human neuralyzer.

## If it were true, where it would sit

PTSD and traumatic-memory disorders, not Alzheimer’s. Erasing a memory is the wrong direction for dementia. The useful version would be a switchable, engram-specific pulse that weakens one fear trace and leaves the rest of the person intact. That product does not exist.

## Do not promote

Not a medicine. Not a trial. Not a device you can buy.
